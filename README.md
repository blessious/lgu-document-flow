# LGU Document Flow

Build the complete frontend-only LGU QR Document Tracking System described in the user prompt. Use React, TypeScript, Vite, Tailwind, shadcn/ui, Lucide, React Router, and Recharts where useful. No backend, database, real authentication, QR processing, uploads, or servers. Deliver a polished responsive clickable prototype with clean reusable components, dedicated TypeScript types, mocks, and a separate data/service layer ready for later Node.js + MySQL integration. Implement the requested login, admin/office dashboards, document registry and registration flow, document details/timeline/workflow, tracking, scanner receive/dispatch/wrong-office states, expected incoming, workflow management/builder, offices/users/references, filing, analytics, reports, notifications, audit/security/settings, and a truly mobile-focused scanner experience with bottom nav. Prioritize working navigation and interactive mock state. Keep UI institutional, blue/neutral, accessible, clear, and production-ready in feel.
